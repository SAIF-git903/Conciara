🧠 Widget User Memory Test

This page demonstrates the chatbot widget with user memory enabled.

User ID: testing

The widget will:

  • ✅ Create a user profile automatically
  • ✅ Store chat history and user preferences
  • ✅ Use LLM to generate personalized, concise responses
  • ✅ Remember context across conversations

📝 Test Scenarios

Try these conversations to see the memory system in action:

  1. First conversation:
    • Say: "I'm a React programmer"
    • Say: "I need a laptop"
    • The bot should remember you're a React programmer and recommend Mac laptops
  2. Second conversation (refresh page, same user ID):
    • Say: "I need a laptop"
    • The bot should remember you're a React programmer and give a personalized recommendation
  3. Budget constraint:
    • Say: "I have a small budget"
    • Say: "What laptop should I get?"
    • The bot should consider both your profession and budget

🔧 Widget Configuration

<script 
  src="http://localhost:3000/widget.js" 
  data-conversatree 
  data-api-url="http://localhost:3001/api"
  data-domain="fashionhub.com" 
  data-user-id="testing">
</script>

Key attributes:

  • data-user-id="testing" - Enables user memory for this user
  • data-domain="fashionhub.com" - Auto-detects configuration
  • Memory is enabled by default (can disable with data-use-memory="false")
