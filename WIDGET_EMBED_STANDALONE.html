My Website with Standalone Chatbot Widget

This example shows how to embed the ConversaTree chatbot using a standalone JavaScript widget (no iframe needed).

✅ Widget Loaded! Look for the chat button in the bottom-right corner.
How it works:
  1. The widget script loads from your ConversaTree frontend
  2. It creates a chat button and window directly in your page
  3. No iframe needed - fully integrated with your site
  4. All styles are injected automatically

Method 1: Simple Script Tag (Recommended)

<!-- Add this before closing </body> tag --> <script src="http://localhost:3000/widget.js"></script> <script> ConversaTree.init({ apiUrl: 'http://localhost:3001/api', treeId: 1, position: 'bottom-right', primaryColor: '#6366f1', title: 'Chat Assistant' }); </script>

Method 2: Data Attributes (Auto-initialize)

<script src="http://localhost:3000/widget.js" data-conversatree data-api-url="http://localhost:3001/api" data-tree-id="1" data-position="bottom-right" data-primary-color="#6366f1" data-title="Chat Assistant" ></script>

Configuration Options

  • apiUrl (required): Your backend API URL
  • treeId (required): Your dialog tree ID
  • position (optional): 'bottom-right' | 'bottom-left' | 'top-right' | 'top-left' (default: 'bottom-right')
  • primaryColor (optional): Hex color for buttons and accents (default: '#6366f1')
  • backgroundColor (optional): Widget background color (default: '#ffffff')
  • textColor (optional): Text color (default: '#1f2937')
  • title (optional): Chat window title (default: 'Chat Assistant')
