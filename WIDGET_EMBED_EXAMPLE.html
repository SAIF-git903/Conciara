My Website with Embedded Chatbot

This is an example of how to embed the ConversaTree chatbot widget in your website.

Instructions:
  1. Make sure your ConversaTree frontend is running on http://localhost:3000
  2. Make sure your ConversaTree backend is running on http://localhost:3001
  3. Replace treeId=1 with your actual dialog tree ID
  4. The chatbot widget will appear in the bottom-right corner

Embed Code:

<!-- Chatbot Widget Iframe --> <div style="position: fixed; bottom: 20px; right: 20px; width: 400px; height: 600px; z-index: 9999;"> <iframe src="http://localhost:3000/widget?treeId=1&apiUrl=http://localhost:3001/api" style="width: 100%; height: 100%; border: none; border-radius: 8px; box-shadow: 0 4px 6px rgba(0,0,0,0.1);" allow="microphone" ></iframe> </div>

With Custom Parameters:

<iframe src="http://localhost:3000/widget?treeId=1&apiUrl=http://localhost:3001/api" style="position: fixed; bottom: 20px; right: 20px; width: 400px; height: 600px; border: none; z-index: 9999;" ></iframe>

Parameters:

  • treeId (required): The ID of your dialog tree
  • apiUrl (optional): The API URL (defaults to http://localhost:3001/api)
